# 显微物镜的光学规格格式与验收口径（第一版）

> 历史记录：本文写于原 zea 项目。「实现顺序」和文中的 DESIGN.md 指 zea 当时的设计文档；`src/zea/…` 是当时的路径，现为 `src/saos/recipes/microscope/…` 与 `experiments/bench/`（calibration.py、runner.py、rounds.py）。文件哈希等实验记录保持原样。

状态：第 1 步审阅已结束。第 3 步在 US 4521083 实施例 1 上实测后，修订了 3.1、3.3 节的实现细节（Zernike 改为一次拟合 66 项；物方远心设置随设计文件沿用），并在 5.4、5.5 节记录了实测结果，详见 [step3-minimal-loop.md](./step3-minimal-loop.md)。对应原 zea「实现顺序」第 1 步。

适用范围：第一版的干物镜，无限远校正，数值孔径不超过 0.65，校正等级为消色差或平场消色差。术语以 [GLOSSARY.md](../../../GLOSSARY.md) 为准。

本文回答三个问题：

1. 光学规格有哪些字段，按约束、性能指标、期望项分别列出单位和 agent 补全时采用的假设。
2. 验收评估怎样逐项判定。
3. 规格差距怎样计算，才能在一个设计任务内保持定义不变、跨调整轮次直接比较。

| 玻璃牌号 | K9、ZF2、QF1、ZF6 等旧牌号（张 p169 实例） | 只用 CDGM.AGF 中状态为 Standard 或 Preferred 的牌号 | 本机目录中 ZF2、QF1 标为 Obsolete（状态 2），对应的 H-ZF2、H-QF1 为在产 |
| 小像差系统的像质判据 | 瑞利判断：波像差峰谷值 ≤ λ/4（李 p299–300；张 p47） | 均方根波像差 ≤ λ/14（Maréchal 判据），作为项目判据 | 李 p299 指出瑞利判断只看最大值，不够严密；Strehl ≥ 0.8 更严格但计算繁杂。均方根和峰谷值之间没有普遍的换算关系，比值取决于像差类型：只有纯离焦时，峰谷 λ/4 准确对应均方根 λ/(8√3) ≈ λ/13.9，λ/14 是它的近似（[TU Delft 讲义](https://qiweb.tudelft.nl/aoi/wavefieldaberrations/wavefieldaberrations.html)）。按 Maréchal 近似，λ/14 对应 Strehl ≈ 0.82（[telescope-optics.net](https://telescope-optics.net/effects1.htm)），与教材的 S.D. ≥ 0.8 相当。选用均方根，是因为它反映整个光瞳的平均情况，不会被光瞳边缘的个别光线左右 |
| "焦深"的含义 | 焦深 = λ/(n′sin²u′)，位于像方（张 p54–55） | 以 ISO 的物方景深 δob = nλ/(2NA²) 作为长度单位 | 两者可以换算：把教材的色差公差 ΔL′_FC ≤ λ/(n′sin²u′m)（张 p55 式 3.13）换算到物方，得到 λ/NA² = 2δob，恰好等于 ISO 的消色差判据。也就是说，教材和 ISO 在这一项上结论相同，本文统一用 δob，避免"焦深"一词同时指两种量 |

## 2. 光学规格的字段

### 2.1 组织方式

每个字段记录四样东西：值、单位、来源（用户给出 / 假设）、依据。来源为"假设"的条目，要逐条写进设计计划交给用户确认。

光学规格在用户确认设计计划后冻结，并带有版本号。验收评估的阈值和规格差距的归一化尺度，都由冻结后的规格值计算，不随设计变化（见第 4.3 节）。

约束分两组。**工作条件**规定设计问题本身（数值孔径、放大倍率、波长……），验收模型直接按它们设置，判定内容是核对设置以及能否完成光线追迹。**结构界限**是有上下限的条件，需要逐项判定。

完整性规则：规格中启用的每一个结构界限和性能指标，在 3.3 节的判定表里都必须有对应的一行，并且有 4.1 节定义的单项差距。工作条件由验收模型直接设置，不计单项差距；按工作条件无法完成光线追迹时，按 3.4 节判为无法评估。用户明确给出的条件，不论默认是否启用，都必须进入验收。以后新增字段时，判定行和单项差距要同时补上，否则该字段不能写进光学规格。

### 2.3 性能指标

"启用"一栏写明该项在什么条件下进入验收。"默认"表示按校正等级自动启用；"用户提出时"表示用户明确提出相应条件时才启用，并且一旦提出就必须验收，与校正等级无关。"标定"一栏为"待标定"的，表示目前没有权威达标线，下面给出的值是初始假设：第 3 步拿复现过的专利物镜核对，真实商品设计普遍过不了的话，修订后再固定为格式中的初始达标线。

|---|---|---|---|---|---|

| `mtf` 调制传递函数 | — | 接收器为相机时默认启用；目视时用户明确提出 MTF 条件时启用（两类） | 记录四项：频率、频率所在的面（一次像面 / 物方）、阈值、视场范围。物方频率按标称 M 换算到一次像面：ν′ = ν_物 / M。相机默认：频率取像素奈奎斯特频率 500/p lp/mm（一次像面，p 为像素尺寸，µm），视场范围 0 到 OFN/2，阈值取用户值，用户没给时取 0.3。目视时四项都由用户给出，缺项由 agent 问出 | 李 p301：对 CCD/CMOS 接收器按奈奎斯特频率提要求。0.3 是假设，没有依据 | 待标定 |

默认情况下，消色差物镜不设视场性能指标。李 p206 和张 p77 都说明，消色差物镜只校正轴上色差、球差和正弦差，场曲不校正，所以默认只把视场像质作为诊断量报告（3.5 节）。用户明确提出离轴像质、倍率色差、MTF 或畸变条件时，按上表启用相应的性能指标，与校正等级无关。用户要求整个视场都平坦清晰时，agent 应当建议改用平场消色差，并作为假设交给用户确认。

不纳入性能指标的项目：

- 色球差：李 p198 说明消色差物镜不校正色球差，ISO 19012-2 也只规定轴向色差。
- 二级光谱（F′、C′ 焦点相对 e 线焦点的偏移）：ISO 只对半复消色差和复消色差规定这一项。
- 分辨率：李 p300 指出，小像差系统的分辨率几乎只由数值孔径决定，不适合用来评价。

### 2.4 期望项

期望项只在验收报告中报告数值，不参与判定，也不计入规格差距。

| 字段 | 单位 | 方向 |

| 片数 | 片 | 越少越好 |
| 工作距离（超出约束下限的部分） | mm | 越长越好 |

| 消色差物镜的平场比 | — | 越高越好 |

### 2.5 派生量

派生量由规格值算出，不由用户填写，写在设计计划中帮助解释规格：

- f_obj = f_TL / M
- 出瞳直径 = 2·NA·f_obj（李 p193 式 12-11）
- 物方视场直径 = OFN / M
- δob、2δob，以及 Berek 景深（3.3 节）
- 分辨距离 0.61λe / NA（李 p195 式 12-17）

## 3. 验收评估

### 3.1 验收模型

验收评估不读取优化目标函数，也不使用设计文件里的分析设置。设计文件采用 saos 的标准设计布局：物面、盖玻片上表面、参考筒镜分别用 `saos:object`、`saos:cover_top`、`saos:tube` 注释标记（见 `src/saos/prescription.py`）。验收评估只取出两者之间的物镜部分，再按下面的步骤重建验收模型，在验收模型上计算。改造步骤是确定的，所以同一个设计文件、同一版光学规格，总是得到同一个结果。

1. **物方**：物面放在标本面上，紧接盖玻片（厚度和材料按规格），然后是空气间隔（即工作距离，是下一步调焦时唯一允许改动的量），之后是物镜各面。没有盖玻片时，物面直接接空气间隔。
2. **孔径**：孔径类型设为 Object Space NA，取值为规格中的 NA。物面紧贴盖玻片时，Zemax 在玻璃中计算的 n·sin u 与空气中的值相同（经过平行平面界面，n·sin u 不变）。
3. **视场**：视场类型为物高，最大值为 OFN/(2M)，使用标称 M，这样视场点不随设计变化。
4. **清除裁光设置**：渐晕因子、面孔径、半口径是三处彼此独立的设置，都可能截掉光线，所以要分别处理：
   - 清除所有视场的渐晕因子。
   - 物镜各面和盖玻片的 Surface Properties > Aperture 一律设为 None，删除圆形、矩形、椭圆、用户自定义的孔径和遮拦，以及 Spider。手册 PDF p278：None 时，凡是能被该面折射的光线都允许通过。
   - 所有半口径设为自动。这样半口径只反映实际光束大小，供通光直径和边缘厚的判定使用。
   - 设计文件中原有的面孔径和遮拦，作为诊断量列入验收报告，提醒 agent 设计依赖过这些设置。
   - 删除之后仍要检查截断状态（3.4 节），不能假定已经没有截断。
5. **波长**：F′、e、C′，主波长 e，等权（或按规格）。
6. **参考筒镜**：在物镜最后一面之后放一个 Paraxial 面，焦距为 f_TL，**OPD Mode = 1**，像面放在它后方 f_TL 处。依据 OS 手册 PDF p235：Mode 1 逐光线积分相位，最慢但最准确；手册建议 Paraxial 面的工作 F 数不要快于 F/4，而这里像方 NA = NA/M ≤ 0.025，即约 F/20，满足这一条件。理想透镜把一束平行光完美成像在焦面上，所以它离物镜多远不影响像质，取一个固定值并写进验收配置即可。
7. **光线瞄准**：开启实际光线瞄准，因为物方 NA 较大，并且光阑位于物镜内部。
8. **物方远心**：沿用设计文件的 Telecentric Object Space 设置。光阑假设在物镜后焦面时，入瞳在无穷远；第 3 步实测，此时不打开这一设置，实际光线瞄准会让边缘光线追迹失败（OpticStudio 2024 R1，错误码为未击中面）。

不用 Afocal Image Space 的原因：ISO 19012-1 的平场判据是在一次像面上定义的；而在无焦模式下，场曲和轴向色差都以屈光度为单位（OS 手册 AXCL 条目，PDF p1106），无法直接与 δ 比较。

### 3.2 验收焦面

使用者是靠移动载物台来调焦的，所以验收评估也只允许改动一个量，即工作距离，来确定焦面：

- 迭代调整空气间隔，直到轴上 e 线的 Zernike Standard 第 4 项（离焦）系数 c4 = 0，收敛判据为对应的物方位移小于 0.01·δob。
- 每次迭代的步长按像方近轴关系估算：Δz′ = 4√3·c4·λ/NA′_act²，NA′_act = NA/M_act，再除以 M_act² 换算到物方。估算步长只影响收敛速度，不影响最终结果，最终结果由 c4 = 0 决定。
- 光线保护：每个试探位置先追迹该波长的轴上主光线和光瞳边缘 36 根光线，有任何一根失败或被截断的位置不做 Zernike 拟合（这类位置的拟合残差上百波，c4 不可用）。起点失败时，先求像面近轴边缘光线高度 PARY = 0 的近轴焦点，从那里重新开始；迭代中某一步落到失败位置时，向上一个有效位置二分回退，最多 6 次。近轴焦点处仍失败，或回退 6 次仍失败，判无法评估（3.4 节）。所有位置都有效时，迭代过程与不加保护时相同。
- 近轴重启的求根最多迭代 20 次，要求工作距离步长小于 `tol_mm`，且 PARY 的绝对值不超过 `NA′·M_act²·tol_mm`；步长变小但残差仍大时不判收敛。恢复失败只表示当前算法未完成评估，不证明镜头不存在可用焦点。第 5 步的输入对照与耗时限制见 [step5-calibration.md](./step5-calibration.md) 3.8 节。

OS 手册 PDF p736 说明，Standard 系数是正交归一的，系数的绝对值就是该项的均方根贡献，所以 c4 = 0 等价于"单独调整离焦能达到的最小均方根波像差"。

以下所有判定都在验收焦面上进行，包括平场比。工作距离和光学长度也在这个焦面上测量。

### 3.3 逐项判定

Zernike 系数统一用 ZERN 计算：Type = 1（Standard），一次拟合到第 66 项（含 ρ¹⁰ 球差项），Samp = 3（128×128），Vertex? = 0。OS 手册 PDF p1153 说明，Term 取 −4 返回相对质心的均方根，取 −1 返回拟合残差；拟合项数取相邻 ZERN 行中最大的 Term，最少 11 项，所以实现上在评价函数末尾临时插入一组相邻的 ZERN 行一起计算，算完删除。拟合残差大于 0.005λ 时，本次评估判为无效（3.4 节），不得私自加大采样再算。

第 3 步实测（US 4521083 实施例 1）：拟合 37 项时，离轴点残差为 0.0047–0.0054λ，正好跨过 0.005λ 的界限；拟合 66 项时降到 0.0001–0.0017λ。c4、c6 在两种项数下相差不超过 5×10⁻⁵ 波，说明截断不影响所用的系数，只影响残差检查。

视场采样规则（视场波像差、倍率色差、MTF、畸变共用）：视场用相对 OFN/2 的归一化值表示。某一项的评估范围为 0 到 r_up 时（r_up 取规格值，没有规定时为 1.0），采样点是 {0, 0.3, 0.5, 0.7, 0.85, 1.0} 中不超过 r_up 的各点，再加上 r_up 本身。所以范围边界总会被评估，即使用户给出的上限不在固定点上，例如 0.6。倍率色差和畸变在视场 0 处恒为 0，可以跳过该点。

#### 视场波像差扣除哪些项

RMS_c 为 ZERN Term −4（相对质心的均方根，已扣除平移和倾斜），c4–c6 为同一视场点在验收焦面上的系数。第一版只有固定验收焦面，不逐视场调焦。只有在另有判据限定某一项时，才允许扣除该项：

| 情况 | σ_f | 理由 |
|---|---|---|
| 平场比同时启用（平场消色差默认如此） | √(RMS_c² − c4² − c5² − c6²) | 离焦和像散已由平场比在同一验收焦面上、用 δ′ 限定 |
| 平场比未启用（消色差物镜在用户提出视场像质条件时） | RMS_c | 没有别的判据限定离焦和像散，必须计入总波像差 |

#### 平场比的计算

**子午、弧矢焦点的位置。** ISO 19012-1 中的 τt、τs 是子午、弧矢像面相对像面的距离。这里的"像面"必须就是验收焦面，否则平场比就和其他判定不在同一个参考面上。所以不直接用 FCGT/FCGS：手册 PDF p704 说明，场曲分析对每个视场点做傍轴光线追迹，给出的是近轴焦点到当前像面的距离。验收焦面却是按 c4 = 0 定义的最佳焦点，两者在轴上就相差一个由球差决定的量，而这个量还会随视场变化。

改为在验收焦面上直接拟合波前。Standard Zernike 中，离焦和像散项为 Z4 = √3(2ρ² − 1)、Z5 = √6ρ²sin2θ、Z6 = √6ρ²cos2θ（OS 手册 PDF p736–737，正交归一）。沿光瞳方向 φ，波前的二次项系数为 a(φ) = [2√3·c4 + √6·(c6·cos2φ + c5·sin2φ)]·λ。二次项系数为 a 的波前，对应的像方纵向离焦为 2a/NA′_act²。子午、弧矢两个方向的 cos2φ 正好反号，所以：

- Δ = (τt + τs)/2 = 4√3·c4·λe / NA′_act²
- \|τt − τs\| = 4√6·√(c5² + c6²)·λe / NA′_act²

其中 NA′_act = NA / M_act，是当前设计在一次像面一侧的数值孔径。这里要把波前测量值换算成长度，属于测量，所以用实际倍率；达标线 δ′ 则只用标称值（见下文）。这两个式子与 Zernike 角度从哪个轴量起、离焦取哪个正负号都无关。轴上的点由验收焦面的定义保证 c4 = 0，像散也为 0，所以 Δ(0) = 0，平场比与其他判定共用同一个参考面。

近似的来源：像方纵向离焦与二次波前的换算是近轴关系。由于 NA′ ≤ 0.025，误差约为 NA′² 量级，即 0.06%；离轴视场在筒镜空间的倾角不超过 (OFN/2)/f_TL = 11/200，带来的余弦修正约 0.15%。FCGT/FCGS 改为诊断量（3.5 节）。在球差很小的设计上，它们减去轴上值后应当与上面的 τ 一致，第 3 步用这一点来核对符号和公式。

**焦深 δ′（目视，ISO 19012-1）。** δ′ 是一次像面上的 Berek 焦深：

δ′ = M² · [ ω·250000 / (NA·M_vis) + λe/(2·NA²) ]，单位 µm。其中 M 为标称倍率，ω = 0.0014 rad（5′），M_vis = 10·M（ISO 规定按 10× 目镜计），λe = 0.546 µm。

δ′ 只由规格值计算，冻结后不随设计变化。它是 \|Δ\| 和 \|τt − τs\| 各自的上限，也就是相对像面的单侧容差。

方括号里是附录 A 的物方 Berek 景深，与附录 A 表值一致：4×/0.10 → 114.8 µm，10×/0.25 → 18.37 µm，40×/0.65 → 1.99 µm。审阅者对照了 ISO 19012-1:2013 样本 PDF 第 7 页（标准正文第 3 页）式 (2) 的页面图像，确认原式含一次像面放大率的平方因子，与上式形式一致。

**视场波像差与平场比的分工。** 平场比启用时，视场波像差扣除 c4–c6，因为离焦和像散已由平场比在同一个验收焦面上用 δ′ 限定。因此视场点上的总波像差并不受 λ/14 约束，离焦和像散部分适用的是 Berek 焦深。这一分工沿用了 ISO 19012-1 的划分。平场比未启用时，按上面"视场波像差扣除哪些项"的表格处理。

**接收器为相机时。** 平场比仍按上面的目视判据计算，用来判定校正等级。相机下视场内是否清晰，由固定验收焦面上的 MTF 判定（2.3 节）。MTF 直接把离焦、像散和其他像差一起计入，并且与像素频率挂钩，不需要再定义一个相机焦深。

#### 候选：相机焦深公式（不参与验收）

下面的公式只作为第 3 步的待验证项记录，不进入光学规格，也不参与判定。

定义 NA′_spec = NA / M（标称）。若要求离焦引起的几何弥散圆直径不超过一个像素 p，近轴关系为弥散圆直径 ≈ 2·NA′_spec·\|Δz′\|，单侧几何容差为 p/(2·NA′_spec)。波动光学项取与 ISO 19012-2 的 δob 相同的单侧形式，即四分之一波长离焦，换算到一次像面为 λe/(2·NA′_spec²)。候选公式为：

δ′_cam = λe/(2·NA′_spec²) + p/(2·NA′_spec)，单侧容差，单位 µm。

两项直接相加，是仿照 Berek 公式的结构，没有依据。验证方法：在第 3 步复现的专利物镜上做离焦扫描，看 MTF 在 500/p lp/mm 处下降到阈值时的离焦量，与 δ′_cam 比较。核对之后再决定是否采用。

#### 放大率的交叉核对

整个验收模型的 PMAG（PDF p1140）是一次像面上的近轴横向放大率。物镜加理想筒镜成倒像，所以 PMAG 应接近 −M_act。核对量 \|(−PMAG)/M_act − 1\| 只作为诊断量报告，不参与判定。它不为零是正常的：验收焦面按实际光线的最佳焦点确定，物面不严格位于物镜的近轴前焦面，物镜与筒镜之间的光束不完全平行。按 40×（f_obj = 5 mm）、物面偏离约 0.5 µm、物镜后焦点到筒镜约 100 mm 估算，偏差约为 0.2%。超过 0.5% 时在报告中提示检查模型。

### 3.4 无法评估的情况

出现以下任何一种情况，本次验收评估的结论为"未通过（无法评估）"，规格差距记为 +∞：

- 检查光线中有任何一根追迹失败或被截断。检查光线是：所有用到的视场点（平场比的 21 点，加上各项按视场采样规则取到的点，含用户给出的范围上限）× 3 个波长，每组包括主光线、光瞳边缘每隔 10° 一根（共 36 根）、0.7 带每隔 30° 一根（共 12 根）。用批量光线追迹读取 errorCode 和 vignetteCode（OS 手册 PDF p1665）：errorCode 非零表示未击中面（正值）或全反射（负值）；vignetteCode 非零表示光线在该面被截断。两者都必须为 0。
- 3.2 节的调焦在 20 次迭代内没有收敛；或调焦时轴上光线在起点和近轴焦点处都失败，或某一步回退 6 次仍落在失败位置。
- ZERN 拟合残差大于 0.005λ。

验收报告要写明失败发生在哪个视场、哪个波长、哪个面。

### 3.5 诊断量

诊断量随验收报告输出，帮助 agent 和用户解释结果，不参与判定：

- 轴上多色 Strehl（STRH，Wave = 0，Huygens 方法，PDF p1048），以及 e 线 Strehl。OS 手册说明 STRH 采用比默认值小一半的像面采样间隔，所以结果会与 Huygens PSF 窗口中显示的值略有差别。
- 轴上 e 线波像差的峰谷值（ZERN Term −8），用来和教材的瑞利判断对照。
- 二级光谱：F′、C′ 的焦点相对 e 线焦点的偏移，以 δob 为单位。
- 色球差：F′、C′ 各自在最佳焦点处的均方根波像差。
- 边缘带和 0.707 带的球差，与教材容限对照：4 倍焦深、6 倍焦深（李 p159 式 10-14、10-15）。
- 消色差物镜在没有启用相应性能指标时的平场比、视场波像差、倍率色差。
- FCGT/FCGS 减去轴上值后的子午、弧矢场曲，用来与 3.3 节基于 Zernike 的 τ 对照。
- PMAG 交叉核对的偏差（3.3 节）。
- 设计文件中原有、在验收模型中被删除的面孔径和遮拦（3.1 节第 4 步）。
- 出瞳位置（对实际筒镜的渐晕有参考价值）。

## 4. 规格差距

### 4.1 单项差距

对每一个启用的结构界限和性能指标 i，在它的所有评估点 k 上计算 g_i,k ≥ 0，取最大值作为单项差距：g_i = max_k g_i,k。

| 判定形式 | g_i,k |
|---|---|
| 上限：v ≤ t | max(0, v − t) / s |
| 下限：v ≥ t | max(0, t − v) / s |
| 双侧：\|v − c\| ≤ t | max(0, \|v − c\| − t) / s |
| 计数型（玻璃状态、面型、片数） | 玻璃状态、面型：违规件数。片数：max(0, N − N_max) |

归一化尺度 s 随光学规格一起冻结，并且必须严格大于 0。规则如下：

- 达标线不为 0 时，s 取达标线本身的大小：放大率取公差（5%），轴向色差取 2δob，波像差取 0.0714λ，工作距离取下限值，平场相关项取 δ′，畸变和 MTF 取各自的阈值，以此类推。于是 g = 1 的意思是"超出了一整份允许量"，各项可以相加。
- 达标线为 0 的字段，规格中必须另外给出 s，否则规格不能冻结。目前只有 `min_air_gap` 属于这种情况，取 s = 0.01 mm，即张 p169 实例中最小的空气间隔。这个值是项目的选择，没有资料依据，含义是"镜片相交 0.01 mm 记为 g = 1"。在下限 0 处、间隔正好为 0 时，g = max(0, 0 − 0)/s = 0，不会出现 0/0。
- 用户给出的阈值为 0 时（例如"畸变为 0"），agent 必须同时问出或假设一个尺度，作为假设交给用户确认。

有一项特殊处理。平场比本身是阶梯函数：采样点离散，PFR 只会跳变，场曲改善时它可能好几轮都不动，规格差距会因此误判为停滞。所以平场比的单项差距不用 PFR 计算，而是取 0 到 0.85·OFN/2 范围内各采样点的 max(0, (\|Δ\| − δ′)/δ′, (\|τt − τs\| − δ′)/δ′)。这个量等于 0 当且仅当 PFR ≥ 0.85，判定结果与 PFR 判据一致，但能连续反映改善。

计数型各项的尺度是 1 件或 1 片。件数是整数，跨轮次直接比较不会有歧义。

### 4.2 合成

规格差距 G = Σ g_i，求和范围是全部启用的结构界限和性能指标。工作条件不计单项差距；无法评估时 G = +∞。期望项不计入。

- G = 0 当且仅当验收评估通过，两者不会互相矛盾。
- 用求和，而不是取各项的最大值：取最大值时，其他项的进步看不出来，而停滞判断恰恰需要看到这些进步。
- 各项等权。加权就要再定一组主观系数，并且同样需要冻结；按达标线归一化后，等权已经可以解释为"超出了几份允许量"。代价是：一项严重超标时会盖过其他项。所以验收报告同时列出每一项的 g_i，agent 调整策略时看分项，停滞判断看 G。

建议停滞判断这样比较。记 G_best 为此前各轮（含第 0 轮，即对初始结构的验收评估）G 的最小值，本轮为 G_k：

| 情况 | 本轮是否算明显缩小 |
|---|---|
| G_k = 0 | 验收通过，停机，不再做比较 |
| G_k = +∞ | 否 |
| G_best = +∞，G_k 有限 | 是。此前各轮都无法评估，本轮首次得到可比较的值 |
| 两者都有限 | (G_best − G_k)/G_best ≥ 1% 时算明显缩小 |

比较之后，G_best 更新为 min(G_best, G_k)。G_best = 0 的情况不会出现，因为出现 G = 0 时已经停机。1% 的阈值和轮数归 DESIGN.md 第 4 步管，本文只保证 G 可以这样比较。

### 4.3 为什么能跨调整轮次比较

一个设计任务内，以下内容全部冻结在"验收配置"里，并随光学规格的版本一起保存：

- 全部阈值和归一化尺度。它们只由规格值计算（标称 M、NA、OFN），不使用设计的实际值。
- 视场采样点、波长与权重、ZERN 的类型、项数（66）和 Samp、OSC 的带、平场比的 21 个采样点、视场波像差的 `field_range`、MTF 的频率、所在面、阈值、视场范围和 Samp、检查光线的分布、Paraxial 面的 OPD Mode 和位置、调焦收敛判据、拟合残差上限。
- OpticStudio 版本（2024 R1.00）、CDGM.AGF 的文件哈希、盖玻片参数。

实现上，第 0 轮把补全后的完整验收配置（上面这些内容，以及评估器自身的常数）写入任务的 `spec/frozen_config.json`，并在 `job.json` 记录其 SHA-256。之后每一轮都按规格文件重新补全并比较哈希：规格路径不同、阈值被原地修改，或评估器常数随代码改变，都会以 `SPEC_CHANGED` 拒绝记录，要求新建任务；只改说明文字不影响补全结果，不会被拒绝。

优化目标函数怎么改，都不会触及这些内容。光学规格如果需要改动，只能由用户重新确认设计计划，或者另建派生任务；规格版本一旦变化，新旧 G 不再比较。

### 4.4 算例

10×/0.25 平场消色差，假设某一调整轮次的测量值如下：

| 项目 | 测量值 | 达标线 | g |
|---|---|---|---|
| 放大率偏差 | 3.0% | 5% | 0 |
| 轴上波像差 | 0.090λ | 0.0714λ | (0.090 − 0.0714)/0.0714 = 0.26 |
| 轴向色差 | 10.0 µm | 8.74 µm | 0.14 |
| 平场（最差点 \|Δ\|） | 2.2 mm | δ′ = 1.84 mm | 0.20 |
| 其余各项 | 达标 | | 0 |

G = 0.60。如果下一轮 G = 0.595，缩小了 0.8%，按 1% 的阈值计为没有明显缩小。

### 5.3 第一版的完成边界

这份文档的完成标准是三条：第一版支持的需求都写全；每一项都有一致、可执行的验收办法；规格差距不随调整轮次改变。尚未实测的内容列在 5.4、5.5 节，交给第 3 步用真实物镜验证，不在本步继续研究。

为此，第一版收紧为：

- 所有视场判定都在固定验收焦面上进行，不支持逐视场调焦。这一项已记入 TODO.md。
- 相机焦深候选公式（3.3 节）只作记录，不进入光学规格，也不参与验收。相机下的清晰度只由 MTF 判定。
- 齐焦距离只记录，不评估。

第三轮修改的内容，除了删除逐视场调焦，只修了会导致漏判或计算矛盾的问题：

- 用户给出的视场范围上限如果不在固定采样点上，原写法不会评估边界，会漏判。现在统一采用"视场采样规则"，把上限本身也加为采样点；检查光线同步覆盖这些点。
- 完整性规则和 4.1 节原写"每一个约束都有单项差距"，但工作条件只是模型设置，没有单项差距可算，两处自相矛盾。现在改为只对结构界限和性能指标计算单项差距；工作条件下无法追迹时，按无法评估处理。

### 5.5 尚未实测验证的事项

留到第 2、3 步：

- 相机焦深候选公式 δ′_cam：用离焦扫描 MTF 核对，再决定是否采用（3.3 节）。
- Paraxial 面 OPD Mode 1 在离轴视场下的计算耗时。如果太慢，可以先证明 Mode 0 与 Mode 1 结果一致，再改用 Mode 0（手册给出了这种做法）。

- ~~基于 Zernike 的 τ 与 FCGT/FCGS（减去轴上值）在小球差设计上是否一致~~。第 3 步实测：不一致。US 4521083 实施例 1（轴上 RMS 0.016λ）上，Zernike 求得的像散差是 FCGT/FCGS 的 1.5–1.8 倍，倍数随视场增大；平均场曲在小视场相差较大（r = 0.3 时 1.7 µm 对 19.0 µm）。原因是高级像散：FCGT/FCGS 用主光线附近的傍轴细光束，只反映光瞳中心的曲率；Zernike 是整个 NA 0.4 光瞳上的最佳拟合。ISO 19012-1 定义像面时假设只有像散和场曲，在这一假设下两者相同，所以标准本身不能裁定。第一版暂时保留 Zernike 方法作为项目判据，理由是它与其他各项共用同一个焦点定义（验收焦面上 c4 = 0）。需要说明两点限度：其一，它是由满孔径波前的低阶系数得到的等效量，尚未验证它与实际的子午、弧矢最佳焦点一致；ISO 19012-1 第 3.2、3.4 条的像面定义带有像差假设，不能据此认定当前算法等同于标准测量。其二，本例中它求得的像散差大于 FCGT/FCGS，但平均场曲在小视场反而更小，所以不能说整套算法更保守。FCGT/FCGS 只作诊断量。
