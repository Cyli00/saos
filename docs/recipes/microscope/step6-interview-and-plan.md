# 第 6 步：需求访谈与设计计划收尾

## 交付范围

访谈在现有 Claude Code／Codex 对话中进行。工具检查结构化事实、字段来源、漏项与范围，HTML 计划供审阅，用户回到对话确认具体版本。确认绑定完整规格、验收配置、结构快照及展示文件；交接时重新验证，改变需求另建任务。

实现为 `interview.py`、`plan.py`、`plan_html.py`、`plan_cli.py`、`plan.css` 和仓库技能 `skills/zea-interview/SKILL.md`。这是显微物镜第一版的计划工作流，不是可处理任意光学系统的自然语言解析器。

## 模拟与真实访谈

本次增加 `tests/fixtures/interview/conversations.json`，由当前模型编写 6 类受控模拟对话，并用 `tests/test_interview_conversations.py` 逐轮回放：

| 情景 | 预期行为 |
|---|---|
| 非专业目视用户 | 问出倍率，保留工作距离，默认 NA 标为假设 |
| 相机测量用户 | 问像元尺寸，保留 0.5% 畸变要求 |
| 4× 用户 | 工作距离未给出前不能生成就绪规格 |
| 用户纠正条件 | 2 mm 改为 3 mm，保留原话，最后版本采用 3 mm |
| 高 NA 油镜 | 明确超范围，不改成干物镜 |
| 光纤侧视用户 | 不套用旧物镜验收，保留未落实条件并转探索任务 |

每轮检查就绪状态、待问问题，最后核对标准字段值和用户来源。事实映射在用例中显式给出；这不是让另一模型独立回答问题的盲测，不据此报告访谈理解准确率。独立模型与跨平台的开放式评估列入 TODO。

真实用户访谈已产生 `work/native-fiber/jobs/20261014-100420-fiber-hemiellipsoid/sources/interview.md`。用户推倒旧方案后，记录移除了双光子和 piezo，并区分已确认条件、假设、未定参数。用户随后明确允许提前做仿真，因此另立显性探索通道，不伪造正式计划确认。
