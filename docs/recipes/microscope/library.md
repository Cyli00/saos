# 初始结构库与基准规格

结构库放在仓库的 `library/microscope/`（可用环境变量 `SAOS_LIBRARY` 改到别处）。一个结构要先通过复现校验才算"收录"（admitted）；结构数量指收录数，不是提取数（DESIGN.md）。

## 流程

```
候选检索 → 筛选（子 agent）→ 面数据提取（子 agent，schema 2）→ saos microscope library check → saos microscope library add → saos microscope library verify
```

1. **候选检索**：在 Google Patents 显微物镜分类（CPC G02B21/02）中按关键词检索，按标题去掉系统类、浸液、反射式等专利。Google Patents 的页面在批量访问时返回 503，所以全文改从 USPTO 下载 PDF（`https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/<号>`）。这些 PDF 只有图像，用本地 RapidOCR 识别成文字。
2. **筛选**：先用正则从 OCR 文字中找出 NA 在范围内的专利，再由子 agent 读全文，逐个实施例记录放大率、NA、浸液、共轭方式、非球面、片数、面数据表所在页、声称的校正等级。只做事实记录，原文没写的字段为 null。
3. **提取**：子 agent 读专利页面图像，按下面的 schema 2 输出 JSON。
4. **`saos microscope library check FILE`**：用独立的近轴计算核对表头的焦距和工作距离。印刷值落在舍入包络内（见下），或与计算值相差不超过 1%，即为一致。不一致时回到页面图像查原因，不直接入库。
5. **`saos microscope library add <id> --extract FILE`**：适配为处方，写入 `library/microscope/entries/<id>/`，状态为 extracted。
6. **`saos microscope library verify <id> --job J`**（需要后台进程）：
   - 当前镜头有未保存修改时返回 `UNSAVED_CHANGES`。先保存，或显式加 `--discard` 放弃当前镜头的修改；这也适用于另一个任务正在加载的镜头。
   - 搭建并做复现校验。焦距、NA、顶点工作距离逐项与原文比较，每项允许的偏差取相对误差 1% 与舍入包络半宽的较大者。全部通过才算收录（admitted），否则拒收（rejected）并写明原因。
   - 在"格式默认规格"下做一次验收评估（probe）。这次评估只填入结构固有的 NA、倍率、视场和盖玻片，界限类取宽松值，测量结果作为标定证据。
   - 按下节规则推导基准规格，并确认原结构在基准规格下 G = 0。

**舍入包络**：专利表格的数字按印刷位数四舍五入，复现精度不可能高于印刷精度。`adapt.rounding_envelope` 按每列的印刷小数位（JSON 数值会丢掉末尾的 0，所以取该列中最多的位数）把半径、间隔、折射率在 ±半个末位内均匀抽样 4000 次，用近轴计算得到焦距和工作距离的分布范围。例如 US 6128139 的折射率只印 2 位小数，f = 20 mm 时焦距的包络半宽约 0.3–0.46 mm，超过 1%。

## 收录与基准规则

| 规则 | 内容 |
|---|---|
| 范围 | 干物镜、NA ≤ 0.65、无限远校正、全球面。有限共轭（160 mm 筒长等）和含非球面的实施例不收 |
| 焦距 | 毫米制数据按原值保存；归一化数据（f = 1）按 f = 200 / \|β\| 保存，即在 200 mm 参考筒镜下保持原放大率 |
| 视场数 | 原文的视场数或像高；原文给了自己的筒镜焦距时，换算为参考筒镜下物方视场不变的值：OFN × 200 / f_tube。原文只给最大物高 y 时，用 `--field-number` 传入 2y × 200 / f。都没有时按 22 假设 |
| 光阑 | 原文印出光阑行时用原文；否则放在物镜后焦面，并打开物方远心设置（原因见[光学规格格式与验收口径](optical-spec-and-acceptance.md) 3.1 节第 8 条） |
| 校正等级 | 原文写了 plan 或 flat field（含"high flatness"这类说法）的按平场消色差评估，否则按消色差 |
| 盖玻片 | 原文工作距离从盖玻片量起时，盖玻片写进处方；缺失字段分别按厚度 0.17 mm、nd 1.523、νd 55 补齐，并记入 assumptions，已给出的字段保留。原文厚度随处方缩放，默认厚度固定为适配后的 0.17 mm。适配报告中的 `cover_glass.thickness` 使用原文长度单位，乘以 `scale` 后才是毫米值；近轴核查采用库中原生焦距对应的缩放倍数 |
| 有依据的判据 | 轴上波像差、轴向色差、正弦差、平场比、放大率、玻璃状态、面型，以及空气间隔非负（边缘相交是物理干涉）不放宽；格式默认规格下不通过，就不能作优化基准（可以留在库里作初始结构） |
| 结构界限 | 工作距离下限取实测机械值 × 0.95；长度、口径上限取默认值与实测 × 1.1 中较大者；玻璃中心厚、边缘厚下限取默认值与实测 × 0.9 中较小者 |
| 待标定的像质阈值 | 视场波像差、倍率色差：默认值能通过就用默认值，否则取实测 × 1.2，并记录为标定证据 |
| 玻璃 | 原文印了牌号且 nd 相差不超过 0.002 时用该牌号；原文没印牌号、折射率列最多只印到 3 位小数时用模型玻璃（nd、νd，此时牌号无法确定）；其余按 nd、νd 找最接近的目录玻璃，距离过大时也用模型玻璃。基准规格允许原结构所用目录中的所有状态（专利多用已停产玻璃），用了模型玻璃的条目另外允许模型玻璃（`limits.glass.allow_model`） |
| 受控扰动 | seed 1，曲率 ±1%，厚度 ±3% |

## 已知局限

- **基准规格由原结构的实测值推出**：工作距离、长度、口径、厚度界限和待标定的像质阈值都按原结构实测值留余量，所以"原结构在基准规格下 G = 0"在构造上就容易成立。它说明的是这个结构能在本流程中复现、并在固定焦面上通过不放宽的那几项判据，不能说明这些推出来的阈值本身合理。受控扰动后的恢复实验（`saos microscope perturb`）用于检验优化流程，以及校准停滞阈值和轮次上限；物理验收阈值的合理性需要独立的使用要求或光学依据，不能由恢复成功推出。
- **替代玻璃的二级光谱**：按 nd、νd 匹配只保证 d 线折射率和主色散一致，部分色散可能不同。对宽波段设计，要用原文给出的多谱线折射率核对替代玻璃（US 11067782 的历史核对记录见 Git 历史）。
- **原文没印的量**：原文没有给视场数、筒镜焦距或工作距离时，入库时由主 agent 按原文其他数据换算或取表中间隔，写进该条目的 doubts，复现校验对这些量的检验力相应变弱。

## 提取格式（schema 2）

```json
{
  "schema": 2,
  "source": {"patent": "US 4521083 A", "assignee": "...", "priority_date": "1982-11-26", "url": "..."},
  "embodiment": "Embodiment 1",
  "units": "mm 或 normalized",
  "order": "object_to_image 或 image_to_object",
  "wavelength": "d、e 或 null（原文未注明折射率对应的谱线）",
  "header": {"f": 1, "NA": 0.4, "WD": 1.334, "beta": -20, "field_number": 27, "image_height": null, "tube_lens_f": null, "other": {}},
  "cover_glass": null,
  "claimed_class": "原文对校正等级的说法，或 null",
  "surfaces": [{"i": 1, "r": -1.740, "d": 0.1668, "n": 1.5927, "nu": 35.29, "glass": null, "aspheric": false, "stop": false}],
  "quotes": {"aperture_stop": null, "working_distance": null, "field_number": null, "wavelength": null},
  "doubts": ["看不清、印刷可疑、与文字层不一致之处"]
}
```

- `surfaces` 只含透镜各面，按原表的方向排列，由 `order` 说明方向；光阑行写 `"stop": true`，平面半径写 null。
- 盖玻片不放进 `surfaces`，写在 `cover_glass`：`{"thickness", "n", "nu"}`。此时 `header.WD` 指盖玻片上表面到第一面的距离。
- 空气间隔所在的面省略 `n`、`nu`；最后一面 `d` 为 null。
- 数字按页面印刷的位数原样抄写，不四舍五入。

## 提取子 agent 的提示词

```
任务：从专利页面图像中逐字提取显微物镜实施例 <名称> 的面数据，按 docs/recipes/microscope/library.md 的 schema 2 写成 JSON。
只做提取，不做光学计算，不推断原文没有的数值；没有就写 null。
输入：<页面 PNG 路径列表>（以图像为准；如有 OCR 文字层，仅作对照）。
需要：表头（焦距、NA、工作距离、β、视场数或像高、筒镜焦距）、全部面数据、光阑行、盖玻片、
折射率对应的谱线、原文对校正等级的说法，以及光阑位置、工作距离、视场数、谱线的原句（注明页码）。
表格方向：说明第 1 面在物方还是像方。
把所有看不清、印刷可疑、与文字层不一致的地方逐条写进 doubts，并写明两种读法。
输出：写入 <输出路径>，最后只回复一句话：已写入，以及 doubts 的条数。
```

提取结果入库前，用 `src/saos/recipes/microscope/paraxial.py` 核对表头：焦距、前焦距（无限远物镜即工作距离），以及原文给出的其他可算量。
