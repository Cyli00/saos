# rtc 核心算法归一（2026-11-05）

目标：所有几何光线算法都由一个带切向的单步派生，只保留一份实现，优化雅可比提速，并保持与 OpticStudio 真值的对账结果不变。用户决定（2026-11-05）：分步全做；`BINARY_2`、`FRESNELS` 迁入内核并修复，不删除；先提交基线再重构。

## 1. 基础算法

一步只做两件事：沿直线走到面上（解 `F(t)=0`），再按切向动量守恒更新方向：

`n'·d' = n·d + (λ/2π)·∇φ_t + s·N`，法线翻到入射侧，`s = −A·N ∓ √((A·N)² − |A|² + n'²)`，`A = n·d + (λ/2π)·∇φ_t`。

透射取负根，反射取正根且 `n' = |n|`；φ≠0 就是衍射。PARAXIAL 是唯一例外：OpticStudio 实测 `n'·tan u' = n·tan u − y/f`，走 tan 空间，保留为特例。

面型只有一个公式，参数表决定它是哪种面：

`z = (cx·x² + cy·y²)/(1+S) + Σα_i·r^(2i) + Σa_i·x^i + Σb_i·y^i`，`S = √(1 − (1+kx)cx²x² − (1+ky)cy²y²)`。

| 面型 | 参数取值 | 求交 |
|---|---|---|
| STANDARD | cx=cy、kx=ky | 闭式 |
| EVENASPH | 同上 + α | 闭式初值 + Newton |
| BICONIC、BICONICX | cx≠cy | 括号保护 Newton |
| BICONICZ | 同上 + a、b | 括号保护 Newton |
| TOROIDAL（旋转半径 0） | cx=0，y 偶次项放进 b | 括号保护 Newton |
| BINARY_2 | 同 EVENASPH，另加相位多项式 | 括号保护 Newton |
| FRESNELS | 折射按 EVENASPH 的斜率 | 平面 |
| PARAXIAL | 平面，tan 空间折射 | 平面 |

## 2. 由切向种子派生的算法

| 切向种子 | 得到什么 |
|---|---|
| 无 | 普通追迹 |
| 设计变量 | 优化雅可比 |
| 发射位置或发射斜率 | 瞄准 Newton 的 2×2 雅可比，以及实际瞄准导数的隐函数项 |

实际瞄准的导数按隐函数定理：`da/dθ = −J⁻¹·(∂stop/∂θ − ∂target/∂θ)`，切向一次走完，事后线性组合。

近轴量（焦距、入瞳、出瞳）在光轴上等于实光线的切向（`iris`、`reflective`、`sequential` 实测差 ≤ 4.4e-16；顶点曲率含矢高的二次项，衍射面另计相位的光焦度），但光瞳对设计变量的导数要二阶，所以仍保留一份 y-nu 追迹，由浮点和 AD 共用，不用嵌套切向。

## 3. 留在约定层的内容

这些是 OpticStudio 的标定事实，物理推不出来，集中放在 `trace.py` 的发射与瞄准目标、`system.py` 的光瞳定义里：Float By Stop Size 的标定、OBNA、R5 自动半口径、R6 表外渐晕、孔径平方半径容差、`iris_real` 未解决的残差。

### 查明的 OpticStudio 规则（2026-11-05 实测）

PETZ 是半径，按 `−1/(n_像·Σ)`，已按下面的规则改好，用例在 `test_omnibus_lock.py`：

- 曲率：偶次非球面计入 α₁；`BICONICZ`、`TOROIDAL` 的 x²、y² 项进近轴量，但不进 PETZ。
- `n_像` 是像面自身的材料，不是像面前的介质。`piA`、`piB` 的像面材料是空气、前一段 n = 1.32633，原来差这个倍数；`codex` 两者相同，所以一直对得上。
- 视场全为零或 Σ = 0 时读数为 0。`piA`、`piB`、`codex` 的视场都是零，所以读数是 0；加 1° 视场后分别是 −0.34637533、−0.24403057、+0.01096375，rtc 现在一致。

`BINARY_2` 的项数 N（2026-11-05 实测）：

- 实光线严格只用前 N 项：`N=1` 时文件里的 A2、A3 不参与，光线差 ≤ 3.1e-15 mm。“按文件实际写的系数算”是错的，rtc 一直按 N 截断。
- 原始文件写 `N=0`（或不写 `XDAT 1`）且带 A1 时，OpticStudio 自相矛盾：实光线不用 A1，近轴量却用。rtc 的 `phase_power` 因此不看 N，ENPP 一致，发射跟着一致，光线差 ≤ 2.9e-15 mm。EFFL、EXPP、EXPD 仍不一致：rtc 的 EFFL 用实光线、不用 A1，22.4726612 对 21.7014600（+3.6%，只是一个样例，不是上限：Codex 的 c=−0.025、M=3、r_n=2.5、A1=−110 样本里 rtc −180.25、OpticStudio +241.40，符号都相反）；EXPP −19.0000 对 −18.9218（0.41%）；EXPD 1.69049 对 1.70910（1.1%）。这种文件只来自手写或外部转换，OpticStudio 另存时会删掉未启用的系数（N=1 时 A2 也清零），重载后两边都对得上。经 API 把 N 改小也会清掉系数，再改回去系数已是 0。

EXPP、EXPD 不是纯近轴量。rtc 保留近轴定义，下面只记录差距：

- **EXPP，瞄准关。** 一条 0.01° 的实主光线，发向主波长的近轴入瞳中心，它在像方与光轴的交点。11 组不重复的真值里，这 10 组差 ≤ 1.7e-13 mm：`iris`、`iris_stop_front`、`reflective` 系、`sequential_opd`；瞄准 real 的 EPD 变体也用这条瞄准关的光线。
- **角度会降级。** 面很强时降到 0.001°、0.0001°，取整数值，反解到 6 位有效数字。与 EPD、波长、圆锥系数无关，随曲率和光线高度变。`codex` 面 5 的曲率 c5：30 → 0.01°，50–200 → 0.001°，300、1000 → 0.0001°；面 3 厚度也有影响（c5 = 200 时 t = 0.4 → 0.01°，t = 1 → 0.001°）。试过 max|m|、max|c·y|，单一阈值都分不开，确切规则未定。
- **EXPD，瞄准关。** 从光阑面高度 1e-3·R 平行出发的实光线，在 OpticStudio 的出瞳面上的高度比，再乘 2R。`reflective`、`sequential_opd`、`reflective_paraxial_after` 差 ≤ 3.6e-15，`iris_stop_front` 2.4e-10，`iris` −2.6e-8，`piA` 2.2e-6。角度降级的 `codex` 用 1e-3 对不上，缩小到 1e-4 这一档还没试。
- **有限物距的 EXPD（OBNA，角度视场）。** 瞄准关是 `2·放大率·近轴光阑高度`，高度取射向近轴入瞳边缘的近轴光线。N-BK7 双片 6 组 NA（0.005–0.1）和物距（60–500 mm）差 ≤ 5.5e-8，已改好；此前错用实光线高度，NA = 0.1 差 −0.129。瞄准近轴、实际时继续分别用近轴和实光线高度，残差差不多（最大 +2.73e-5、同一组），R 选对了，剩下的放大率项属于下面的未定规则。
- **瞄准开。** 这是 `iris_real` 标 `xfail` 的原因，规则未定。`iris` 的 EXPP 随最大视场变：F = 0.1° 偏 7.8e-6，1° 偏 7.8e-7，3° 偏 2.6e-7，10° 偏 1.0e-4（相对近轴）。不是 FLOA 特有：EPD 5.8 配近轴瞄准和 FLOA 给出同一个值 −26.04017531。开关瞄准缓存 EXPP 不变，同一设置重复读数相同，所以不是数值噪声。小视场和满视场的实瞄准主光线都对不上。`reflective_stop_on_secondary_real` 在原视场上恰好等于瞄准关的值。

近轴定义的差距：真值变体 EXPP 相对差约 3.9e-8 以内（`iris_real` 4.0e-6），`piA` 8.6e-6，`codex` 0.4%；EXPD 真值变体约 8.3e-8 以内（`iris_real` 3.9e-6），`piA` 8.0e-6，`codex` 0.8%。不改的原因：`codex` 这种情形要先定出角度规则，固定用 0.01° 反而偏 2.8e-3 mm，比近轴差两个量级。
