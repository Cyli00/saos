# 专利结构入库不调用 patent-lens-to-excel 的代码，改为按处方由 saos 搭建

Zemax 自带样例中没有显微物镜，初始结构库主要来自教材和专利实施例。`ref/repo/patent-lens-to-excel` 已经能把专利面数据转成 `.zmx`，所以最初倾向复用它。用 US 4521083 实施例 1 走完提取 → 适配 → 搭建 → 复现校验 → 验收 → 扰动 → 恢复之后，最终没有调用它的任何代码。原因有三：

- 它的 `.zmx` 生成写死了摄影镜头的口径模型（近轴工作 F 数、逐结构渐晕、对焦结构），表达不了显微物镜需要的物方数值孔径、物方远心和理想参考筒镜。
- 按处方直接搭建后，这些设置都能逐项设定，并可当场回读核对。
- 它的玻璃匹配只看 nd/νd，不读目录中的状态字段，而光学规格的玻璃约束要用状态判断是否在产。

因此入库流程是：把面数据提取为 JSON → `saos microscope library check` 近轴预筛 → `library add` 适配成处方入库 → `library verify` 复现校验。从它借鉴的只有做法，没有代码：

- 以 JSON 中间格式承接提取结果；
- 玻璃按 nd/νd 加权最近邻匹配。

它的表格页定位（`find_tables.py`，依赖本机未安装的 poppler）等到要批量处理长篇专利时再评估。
