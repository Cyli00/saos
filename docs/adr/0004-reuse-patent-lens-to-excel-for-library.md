# 建初始结构库时复用 patent-lens-to-excel（待验证）

Zemax 自带的 251 个样例中没有显微物镜，第一版的初始结构库主要来自教材和显微镜厂商的专利实施例。`ref/repo/patent-lens-to-excel` 已经能把专利面数据转成 `.zmx`，所以倾向于复用它，而不是像 ADR-0001 那样重写。

但它是为摄影镜头写的，不能直接用于显微物镜：`make_zmx.build()` 必须读取 `zmx.configs`，而 `lensmath.py` 在没有 `zmx.focus` 时不会生成这个字段；它默认按"无限远加近距对焦"的方式生成多个配置，孔径类型也固定为近轴工作 F 数。显微物镜专利给出的是固定的面数据表、物方数值孔径和工作距离，需要另外处理共轭关系和孔径的换算。

专利工具只在入库流程中使用，设计任务运行时不会调用入库流程（库中没有合适结构时，只列出候选专利，交给用户决定是否离线入库）。

因此复用的范围先不确定。先用一个完整的显微物镜专利实施例走通提取、适配、加载到 Zemax、复现专利中的指标这几步，再决定复用到哪一层（只用表格提取和玻璃匹配，还是包括 `.zmx` 的生成）。验证之后，本 ADR 改为 accepted，并写明复用范围。
