# 以 Python 为主，只有逐光线计算用 C#

同机实测（2024 R1，后台模式）：读写编辑器单元格 Python 1025 µs/次、C# 930 µs/次，基本一样，瓶颈在 OpticStudio 本身；批量追迹 1 万根光线时，加入光线 Python 0.108 s、C# 0.006 s，读取结果 Python 0.132 s、C# 0.001 s。所以语言只在"逐根处理光线"时有影响。命令行工具默认用 Python 写，因为 agent 更容易阅读和修改，后处理也更方便；只有需要自定义逐光线计算的命令才用 C# 写。agent 调用的都是同一套命令，接口的 JSON 格式不受底层语言影响。
